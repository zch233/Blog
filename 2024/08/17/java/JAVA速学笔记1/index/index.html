基础概念

JAVA 三大块

  • JavaSE（Java Standard Edition）标准版（基础）
  • JavaEE（Java Enterprise Edition）企业版（大多数选择）
  • JavaMe（Java Micro Edition）微型版

JAVA 有十大特性，以下两点最重要

  • 面向对象，一切皆是对象
  • 可移植性（跨平台），一次编译，到处执行
